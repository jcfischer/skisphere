# Data provenance

Every generated byte in `src/data/sky.generated.ts` comes from the files in
`data/raw/`, produced by `tools/build-data.ts`.

| File | Source | What it provides | Terms |
|---|---|---|---|
| `stars.6.json` | [d3-celestial](https://github.com/ofrohn/d3-celestial) `data/`, Olaf Frohn — Hipparcos-derived | ~5000 stars to V ≈ 6: J2000 position, V magnitude, B−V colour | BSD-style (see `LICENSE.d3-celestial.txt`) |
| `starnames.json` | same | proper, Bayer, Flamsteed, variable and catalogue names keyed by HIP number, plus parent constellation | same |
| `constellations.json` | same | IAU constellation names, genitives, display rank, label anchor | same |
| `constellations.lines.json` | same | stick figures (IAU-style line figures) as RA/Dec polylines | same |
| `constellations.bounds.json` | same | IAU 1930 constellation boundary rings | same |
| `mw.json` | same | Milky Way outline in five opacity levels | same |
| `messier.json` | same | Messier objects: type, magnitude, apparent size | same |
| `land-110m.json` | [world-atlas](https://github.com/topojson/world-atlas) 2.0.2, built from [Natural Earth](https://www.naturalearthdata.com/) 110m | coastline / land outlines for the location picker | Natural Earth is in the public domain; world-atlas is ISC |

Reference values used for verification (`tools/verify-astro.ts`):

- **NASA JPL Horizons** (DE441) ephemerides, cached under `data/horizons/`.
  Contact: <https://ssd.jpl.nasa.gov/api/horizons.api>. Not redistributed; only the
  comparison results are recorded here and in `README.md`.
- **astronomy-engine** 2.1.19 (MIT) for planetary/lunar ephemerides, GAST and
  rise/transit searches; its own accuracy claim is ±1 arcminute against Horizons.

## Notes on derived numbers

- Right ascension is normalised to [0°, 360°); d3-celestial publishes longitude
  wrapped to [-180°, 180°].
- Constellation boundaries and the Milky Way outline are Ramer-Douglas-Peucker
  simplified at 0.05°/0.06° tolerance: invisible at the rendered scale, roughly a
  third of the source size.
- Star names are kept for stars brighter than V = 5.5; fainter named stars stay in
  the catalogue but are not labelled.
- Positions are epoch J2000. Precession and nutation to the equator/equinox of date
  are applied at run time by `src/astro.ts`.
